01 — Platform

One place for the work, the money and the paperwork

RCS replaced a spread of spreadsheets, shared drives and standalone tools with a single system. Every module sits on the same identity, the same master data and the same audit trail, so a project manager, a finance lead and an administrator are all looking at the same numbers.

Projects

Projects & contracts

Project setup, contract structures, milestones and progress claims tracked against the commercial terms that actually govern them.

Finance

Billing & cost control

Timesheets, disbursements, invoicing and cost-to-complete in one flow, reconciled rather than re-keyed.

Documents

Document control

Controlled documents with revisions, transmittals and generated output — including automated bookmarking and compression for large contract sets.

Identity

Identity & access

Single sign-on, role-based permissions and per-tenant configuration handled centrally by RCS-Identity, not per screen.

Admin

Master data & admin

Clients, staff, rates, cost codes and lookups administered once through RCS-Admin-Core and consumed everywhere.

Insight

Reporting

Operational dashboards and exports built on the live database, so management reporting stops being a monthly reconstruction.

02 — Architecture

Built as parts we can replace

An Angular workspace on the front, a gateway in the middle, focused .NET services behind it and PostgreSQL underneath. Each service owns its own concern, which is what lets us ship one module without holding the rest of the platform still.

Frontend

A workspace, not a monolith of screens

Feature modules load on demand and share one component library, so a pattern fixed once is fixed everywhere. New modules start from the same shell instead of a blank page.

Backend

Services with clear edges

Identity, admin and domain concerns are separate deployables behind one gateway. Local environments run several frontends against the same API without CORS gymnastics.

04 — Delivery

How the year went

Numbered because it is a sequence: each step made the next one cheaper.

  1. 01Q1

    Foundations hardenedShipped

    Branch protection and required reviews on the main development branches, migrations brought fully into source control, and local environment setup reduced to a documented, repeatable path.

  2. 02Q2

    Shared component libraryShipped

    Common tables, forms and layout primitives pulled out of individual screens into one versioned library with design tokens. Module work sped up and the UI stopped drifting between areas.

  3. 03Q2

    Automated release pipelineShipped

    GitHub Actions builds into Octopus Deploy, with a Cloudflare Workers service posting build and deployment status to the team’s Discord channels. Releases became routine instead of an event.

  4. 04Q3

    AI-assisted code reviewIn progress

    An automated reviewer runs on every pull request in the frontend repo, catching the mechanical problems before a human reads the diff so review time goes to design decisions.

  5. 05Q4

    Next modulesPlanned

    Remaining finance and document-control workflows onto the platform, deeper reporting, and continued reduction of the manual steps still living outside RCS.

05 — Practice

What we do differently

The platform is the visible half. The other half is the practice around it — the reason a change lands the same way on a Tuesday afternoon as it does on a quiet Friday.

Review

Every change is read

Protected branches, required reviews, and automation that handles the mechanical pass. Reviews are about architecture, not formatting.

Tooling

We build our own tools

Worktree workflows for parallel branches, custom automation for document generation, notification pipelines wired to the systems we already use. If a task is repeated, it gets scripted.

Reuse

Solve it once

Shared components, shared configuration patterns, shared identity. New work inherits decisions instead of relitigating them.

Ownership

From branch to production

The same team designs the interface, writes the service, runs the pipeline and answers when something breaks. Nothing is thrown over a wall.
